# The Syndicate Club reference kit (Salo internal)

The website reference for a brand The Syndicate Club supplied. It is Salo's working document for the website, for the team and for Claude, not a client deliverable, and it doesn't replace The Syndicate Club's own guidelines. Where the two differ, theirs win.

- `reference-kit.html`: the Brand chapter (what the kit is built from, positioning and voice, colour, type, logo, imagery, gaps), then the website's elements, compositions, motion, logo pieces and rules, with an accent switcher if a choice is open.
- `syndicate-website-rules.md`: the technical guardrails Claude reads before any website work. Embedded in the kit and downloadable from it.
- `concept-review.html` and `concept/` (once turned on): the website concept with comments, content edits and sign-off.

## Running it

Run it locally: `python3 -m http.server 8000` in this folder, then open http://localhost:8000/reference-kit.html. Don't publish it to public hosting. When the client needs to see the concept, put it on Salo's secure hosting (behind a real login), not on public GitHub Pages.

## Keep it current

When The Syndicate Club sends new brand material, update the Brand chapter and the gaps table, and save the change to the brand brain.
